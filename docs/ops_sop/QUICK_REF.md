# SPECTREBAND QUICK REF — POCKET CARD

## BAND LIGHTS
- Solid green = your team color, alive
- Flashing white = you got hit, MARK IT
- Pulsing yellow = Hunter-Prey pulse incoming
- Solid purple = you are the Spectre
- Dim red = return to checkpoint
- Off = dead or respawning

## BUTTON
- Short press (tap) = mark hit / confirm
- Long press 2s = team select (red)
- Long press 4s = team select (blue)
- Double tap = ping location to team

## CHARGING RACK
- Red LED = charging
- Green LED = full
- No light = check pogo pins

## SERVER COMMANDS
```
cd paintball-field/server
python src/main.py --config configs/blitz_outdoor_50x30.json
```

## MODES
- Hunter-Prey: 3s wall vision every 60s. Best for beginners.
- Ghost: Dead = spy. Keeps kids engaged.
- Domination: Hold zones. Best for large groups.
- CTF: Grab flag box. Fast and fun.

## EMERGENCY
- Band fire → water bucket
- Injury → remove band, first aid
- Storm → power down everything
