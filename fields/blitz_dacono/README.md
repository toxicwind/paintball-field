# Blitz Dacono — Field SDK v1.4

> **Modular field configuration system.** Generate 3D renders from config. Satellite photos are raw reference only.

## What's New in v1.4

**3D Field Renderer** — `field_sdk/renderer.py` generates professional 3D field maps from config JSON. No satellite photos needed for visualization.

```bash
python3 field_sdk/renderer.py fields/blitz_dacono/airsoft1/config.json output.png
```

## 3D Renders

Each field has a `render_3d.png` generated by `field_sdk/renderer.py`:

- **Green surface**: Field playing area
- **Brown/red/blue boxes**: Bunkers (varies by type)
- **Blue tower (GW)**: LoRa gateway
- **Teal towers**: WiFi AP positions
- **Green markers (O1-O8)**: Objective nodes
- **Purple/orange/red overlays**: Sub-zone boundaries (Military only)

## Important Notes

**3D renders are primary.** `render_3d.png` is generated from config data and is the canonical visualization. `visualization.png` (satellite overlay) is legacy reference.

**Raw imagery is disposable.** Satellite photos go stale. The 3D renderer regenerates from config JSON whenever needed.

**Configs are portable.** `airsoft1/config.json` can be copied to any venue and adapted in 10 minutes.

## Adding a New Field

1. Copy `templates/field_sdk_template.json` to `fields/<venue>/<field>/config.json`
2. Fill in dimensions, features, AP placement, calibration
3. Generate 3D render: `python3 field_sdk/renderer.py config.json render_3d.png`
4. Run mode compatibility rating using `modes_matrix.json` as reference
5. Commit.
