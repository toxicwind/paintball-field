# Ghost

## Overview

Eliminated players become invisible "ghosts" that can still see all player positions and relay intel to living teammates. Ghosts appear on their team's bands as faint green dots (with "GHOST" label). Living players cannot see ghosts. This keeps eliminated players engaged and turns death into an intel role.

## Rules

| Rule | Detail |
|------|--------|
| Teams | 2 teams, 6 players each |
| Ghost | Dead player becomes invisible spotter |
| Ghost Vision | Sees all players (both teams) |
| Ghost Comms | Can only communicate via band; no voice (optional honor rule) |
| Win Condition | First team fully eliminated loses |

## Band Behavior

| State | OLED Display | Haptic | LED |
|-------|-------------|--------|-----|
| Alive | Green dots = teammates + ghosts; red = enemies | Standard | Team color |
| Ghost | All dots visible (both teams) + "GHOST MODE" | None | Dim green |
| Ghost spotting | Can "ping" location to teammates (band vibrates for team) | Team buzz | White flash for team |
| Last alive | All ghosts focus on you; you see all enemy positions | Heartbeat | Rapid team color |

## Tier Requirements

- **Tier 0 only** — Core band ($12/player)
- No additional hardware needed

## Variants

| Variant | Change | Difficulty |
|---------|--------|------------|
| **Poltergeist** | Ghosts can "haunt" enemies (vibrate their band randomly) | Medium |
| **Revive** | Ghosts can revive one player per match (30s channel) | Easy |
| **Ghost Betrayal** | Ghosts can switch to enemy team after 2 min | Hard |
